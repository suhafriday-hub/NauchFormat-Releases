# Границы поддержки 0.5.0

НаучФормат помогает оформить документ, но не гарантирует принятие статьи
издателем и не заменяет проверку содержания и внешнего вида.

| Область | Поддержка и ограничение |
|---|---|
| Форматы | Шаблон DOCX/DOTX, статья DOCX. DOC не поддерживается. |
| Структура | Правила и оценки уверенности; неоднозначные решения проверяет пользователь. |
| Порядок | Сохраняется исходный порядок блоков. |
| Таблицы, рисунки, формулы | Проверены обычные таблицы, растровые DrawingML-рисунки и OMML. |
| Сложные объекты | OLE, SmartArt, диаграммы, сноски, комментарии и сложные поля не входят в гарантию переноса. |
| Требования | Извлекаются текст и некоторые числовые правила; произвольный язык не превращается полностью в проверки. |
| Ссылки | Проверяется числовая схема, включая группы номеров. Другие схемы требуют редактора. |
| Нейросеть | Необязательна. Недоступная локальная модель заменяется правилами с предупреждением. |
| Отмена | Выполняется на контрольных точках; начатый сетевой запрос может ждать до тайм-аута. |
| Макет | Нет встроенного рендерера страниц Word; переносы и пагинацию проверяют в редакторе. |
| Испытания | Автотесты используют в основном синтетический корпус; это не оценка качества на всех реальных статьях. |

Перед обработкой сложных документов сохраняйте оригинал; перед публикацией
просмотрите таблицы, формулы, изображения, ссылки и разрывы страниц.
