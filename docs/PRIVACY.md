# Конфиденциальность

Обычная обработка документов выполняется локально. В приложение не встроены
аналитика использования и автоматическая отправка статей или отчётов об ошибках.
Настройки сохраняются в профиле текущего пользователя; ключ внешнего API
не сохраняется в настройках.

Автоматическая проверка обновлений обращается к GitHub. GitHub получает
обычные сетевые сведения, включая IP-адрес, а запрос содержит номер версии
НаучФормат. Документы в эти запросы не включаются. Проверку можно отключить.

Локальная Ollama принимает только loopback-адреса. При явно включённом внешнем
API спорные фрагменты текста длиной до 4000 символов передаются указанному
провайдеру; его обработка данных определяется его собственными условиями.

Удаление приложения не удаляет подготовленные документы и экспортированные
отчёты. Настройки Windows хранятся в профиле пользователя
`HKEY_CURRENT_USER\Software\NauchFormat\NauchFormat`.
