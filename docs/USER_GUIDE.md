# НаучФормат 0.6.0: руководство

## Установка и обновление

Скачайте установщик из [официального выпуска](https://github.com/suhafriday-hub/NauchFormat-Releases/releases/latest).
Windows 10/11 x64; установка для текущего пользователя. Python и Microsoft Word
для обработки не нужны. Для проверки окончательной вёрстки нужен редактор DOCX.

Кнопка «Обновить» справа на верхней панели проверяет GitHub. Программа также
проверяет обновления при запуске. Скачанный установщик проверяется по SHA-256;
после подтверждения приложение закрывается и запускается обновление. Документы
не удаляются. Автоматическую проверку можно отключить в настройках.

## Главный экран

Вверху — «Документы», «Вид», «Подготовить», «ИИ и отчёты», «Очистить»,
«Обновить» и «Настройки». Ниже — выбранные файлы. Слева показан текст исходника,
справа — результат; под ними статистика. Это текстовый просмотр, а не изображение
страниц Word. Двойной щелчок по результату открывает его в редакторе DOCX,
по отчёту — отчёт в браузере.

## Статья из диплома или большой работы

1. В «Документах» откройте исходный DOCX и шаблон журнала DOCX/DOTX.
2. Выберите «Подготовить → Статья из диплома — отбор и редактор».
3. Введите тему, желаемый объём основного текста и число рисунков.
4. На вкладке «Титульная часть» проверьте название, автора, организацию,
   аннотацию, ключевые слова. УДК вводит автор; редакционные DOI и даты
   программа не придумывает.
5. Во вкладке «Отбор и редактирование» включайте нужные фрагменты флажками.
   Выбор строки показывает полный текст для редактирования. Можно изменить
   название раздела и подпись рисунка. Номер блока указывает положение в исходнике.
6. Заполните английские поля и описания процитированных источников.
7. Нажмите «Сформировать DOCX и отчёт». Сравните текст, изучите замечания,
   откройте DOCX и проверьте страницы.

Программа предлагает исходные фрагменты и сохраняет их порядок. Она не заменяет
научного редактора: сокращённый текст нужно связать, убрать повторы и проверить
выводы. Формулы и сложные объекты автоматически не включаются; таблицы выбираются
вручную. Если предложение зависит от исключённого рисунка, таблицы или формулы,
оно не входит в рекомендуемый отбор.

Рядом с DOCX сохраняются `.plan.json`, `.report.html` и `.report.json`.
План можно открыть через «Документы → Открыть план статьи» и продолжить работу.
Сохраняйте оригинал и шаблон: план содержит пути и контрольные суммы этих файлов.
При их изменении потребуется новый план. Для переноса результата вместе с планом
и отчётами используйте «Открыть папку результата» и скопируйте весь комплект.
«Сохранить результат DOCX» копирует только документ.

## Оформление почти готовой статьи

Выберите «Подготовить → Оформить готовую статью — сохранить содержание».
Этот режим переносит текст, обычные таблицы, растровые рисунки и OMML-формулы
с применением стилей шаблона. Исходник не сокращается. В «Вид → Структура и журнал»
проверьте неоднозначные сопоставления, затем повторите формирование.
«Вид → Сведения о результате» показывает метрики и предупреждения.

## Модели и конфиденциальность

Отбор материала работает локально без нейросети. Настройки Ollama и внешнего API
относятся к помощи в классификации блоков при оформлении. Внешний API требует
отдельного согласия на передачу текста. Подключение модели не превращает отбор
диплома в автоматическое написание новой научной статьи.

## Если что-то не работает

- Проверьте формат: DOCX для исходника, DOCX/DOTX для шаблона.
- При занятом файле закройте его в Word и выберите новое имя результата.
- При ошибке обновления можно скачать официальный установщик вручную.
- Для сообщения об ошибке укажите версию, шаги и текст ошибки. Используйте
  обезличенный пример вместо конфиденциальной рукописи.
