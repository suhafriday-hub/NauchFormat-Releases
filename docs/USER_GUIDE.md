# Руководство пользователя

## Установка

Скачайте `NauchFormat-Setup-0.5.0-x64.exe` из официального выпуска GitHub.
Запустите установщик и выберите папку. Установка по умолчанию выполняется
для текущего пользователя. Python, Microsoft Word и Ollama для обычной работы
не нужны. Целевая платформа — Windows 10/11 x64.

## Подготовка статьи

1. На странице «Материалы» выберите издательский шаблон DOCX или DOTX.
2. Выберите исходную статью DOCX. При необходимости добавьте требования
   издателя в TXT, PDF или DOCX.
3. Нажмите «Сформировать статью» и дождитесь завершения.
4. На странице «Структура» проверьте неоднозначные сопоставления. Подтверждайте
   только подходящие варианты и повторно сформируйте документ после изменений.
5. На странице «Результат» сохраните DOCX и отчёт. Откройте готовый документ
   в Word или совместимом редакторе и проверьте внешний вид.

Программа не переписывает содержание статьи. Она переносит блоки и применяет
стили шаблона. Для неподтверждённых неоднозначных блоков используется нейтральный
стиль. Исходные документы не перезаписываются; новый результат получает
уникальное имя. Если изменить исходные файлы во время работы, обработку
нужно повторить. Кнопка отмены останавливает документ на ближайшей контрольной
точке; незавершённый результат не выдаётся за готовый.

## Дополнительная модель

В настройках можно подключить локальную Ollama, выбрать установленную модель
и проверить соединение. Это необязательно. Если модель недоступна, обычная
обработка продолжается по правилам с предупреждением в отчёте.
Внешний API активируется только с отдельным согласием на передачу текста.

## Обновления

При запуске приложение проверяет официальный канал. При наличии новой версии
предлагает скачать установщик и после проверки SHA-256 — установить его.
Проверку можно запустить вручную или отключить в настройках канала.
Обновление устанавливается поверх прежней версии. Приложение закрывается
для замены файлов; документы остаются на месте. Для перехода с прежних версий
без настроенного канала один раз установите 0.5.0 вручную.

## Если что-то не работает

- Убедитесь, что выбран DOCX/DOTX, а не старый формат DOC или PDF статьи.
- Закройте документ в редакторе, если файл занят, и сохраните результат в папку
  с правом записи.
- При ошибке обновления проверьте интернет и повторите попытку. Можно скачать
  официальный установщик вручную со страницы выпусков.
- Для сообщения об ошибке укажите версию, шаги и текст ошибки. Не прикладывайте
  конфиденциальную статью; по возможности создайте обезличенный пример.

Сложные объекты и точное издательское соответствие требуют ручной проверки.
Границы поддержки перечислены в [LIMITATIONS.md](LIMITATIONS.md).
